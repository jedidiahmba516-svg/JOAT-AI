# J.O.A.T. Privacy Policy

**Version:** 1.0 — Beta

J.O.A.T. is designed around local-first processing. The final public policy must match the actual implementation and services used by the released build.

## Data stored locally
Depending on enabled features, J.O.A.T. may store conversations, memory, goals, tasks, settings, activity metrics, and uploaded images on the user's computer.

## Local AI model
When the local GGUF provider is used, prompts are processed by the model running on the user's computer. J.O.A.T. does not intentionally send those prompts to a remote AI provider through the local provider.

## Network features
Web research, speech recognition, update checks, and optional integrations may contact external services. The release build must disclose each service and its purpose here.

## User controls
The application should provide settings for activity logging, voice, integrations, permissions, and local data management.

## Data deletion/export
The release should provide a documented way to export and delete local J.O.A.T. data.
