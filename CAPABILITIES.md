# J.O.A.T. Assistant Capability Map

J.O.A.T. is designed as a general desktop assistant with modular capabilities:

- Conversation, context, memory and semantic memory
- User profiles, goals, tasks and activity tracking
- Web search, research, webpage reading and source collection
- Calculator, system diagnostics and approved desktop tools
- Windows app discovery and launching
- File workspace and document utilities
- Voice input/output and multimodal/image intake hooks
- Agent planning, execution, verification and recovery
- Persistent settings, backups, plugins and privacy controls
- User-selectable tone/personality and bounded emotional expression
- Assistant modes for normal, study, coding, research and other workflows

The local engine is intentionally modular. Advanced natural-language reasoning and vision require a compatible model/provider; the app should never pretend a rule-based engine is a full foundation model.
