# J.O.A.T. Standalone Test Build

Python **3.11, 3.12, and 3.13** are supported.

## Install
1. Extract the ZIP.
2. Open the extracted `JOAT_Merged_Standalone` folder.
3. Run `install.bat`.
4. Run `start.bat`.
5. Open `http://127.0.0.1:5000`.

The installer automatically tries the Python Launcher, the `python` command, and common Python 3.13 installation paths.
