# J.O.A.T. Desktop + Start Menu shortcuts

Run `INSTALL_JOAT.bat` once.

It installs the Python requirements and creates:
- `J.O.A.T.` on the Windows Desktop
- `J.O.A.T.` inside Start Menu > J.O.A.T.

The shortcuts launch `desktop_app.py` directly with `pythonw.exe`, so no Command Prompt window is needed.

If a `joat.ico` file is added to this folder later, the shortcuts will automatically use it as the icon when `CREATE_SHORTCUTS.bat` is run again.
